# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that analyzes resumes, evaluates ATS compatibility, identifies skills, education and experience, and provides intelligent suggestions for improving resume quality.

## 🚀 Features

- 📄 Resume PDF Upload
- 🤖 AI-Based Resume Analysis
- 📊 ATS Score
- ⭐ Resume Quality Evaluation
- 🛠️ Skills Detection
- 🎓 Education Detection
- 💼 Experience Detection
- ❌ Missing Skills Detection
- 💡 Resume Improvement Suggestions
- 📋 Resume Preview
- 📑 Professional PDF Report Generation
- 🌐 Web-Based Interface

## 🧠 How It Works

1. Upload your resume in PDF format.
2. The system extracts text from the resume.
3. Resume content is analyzed using the AI semantic model.
4. Important information such as skills, education and experience is detected.
5. An ATS score is calculated.
6. Missing skills and improvement areas are identified.
7. A detailed analysis is displayed.
8. A professional PDF report can be downloaded.

## 🛠️ Technologies Used

- AI / Semantic Analysis
